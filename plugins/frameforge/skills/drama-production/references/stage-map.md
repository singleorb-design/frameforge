# 短剧影像生产阶段映射

本文件把外部创作 skill 的方法映射为 FrameForge 画布阶段。使用时只读取当前任务需要的阶段。

## 融合原则

- FrameForge 是影像生产画布，不是完整网文写作工具箱。
- 优先融合 `short-drama-image-prompts`、`short-drama-storyboard`、`short-drama-video-prompts`、`acting`、`lira`、`shot-drama-scene-layout` 的方法。
- `story-long-write`、`story-long-scan`、`story-cover`、`story-import` 等纯网文能力保持外部 skill，不纳入默认画布链路。
- 每个阶段都应产生可编辑节点或明确的节点创建计划。
- 不为“流程完整”虚构上游文件。用户已有单集剧本时，可以直接进入资产、分镜或视频 Prompt。

## 阶段 0：输入与范围

适用输入：

- 一集剧本、章节、分镜表、镜头清单、角色设定、场景参考图、道具说明。
- 多集长材料时，先让用户选择本轮集数或章节，默认只处理第一集/第一章。

画布产出：

- `剧本｜第 N 集｜标题`
- `范围说明｜本轮处理`

检查点：

- 记录本轮范围：集数、场次、镜头 ID 或章节标题。
- 不把整本长篇直接塞进一个生成请求。

## 阶段 1：开发/改编入口

适用场景：

- 用户只有点子、章节或小说片段，希望变成短剧/AI 漫剧生产方案。
- 用户需要从多集材料整理分集地图，但还没有稳定剧本。

参考能力：

- `novel-adaptation`：轻量章节/片段改短剧。
- `short-drama-develop`：故事引擎、创作简报、分集地图。
- `short-drama-novel-analyze`：整本长篇只读分析和分集候选。

画布产出：

- `创作简报｜项目名`
- `故事引擎｜项目名`
- `分集地图｜EP001-EP00N`
- `待确认问题｜改编边界`

检查点：

- 标出不可改事实、可改空间、结局承诺和制作边界。
- 没有原文时不要凭书名回忆剧情。
- 用户已经给出正式剧本时，不强制补开发阶段。

## 阶段 2：资产拆解

适用场景：

- 已有剧本或分镜，需要人物、场景、道具、状态和声音方向。

画布产出：

- `人物资产｜角色名`
- `场景资产｜地点名`
- `道具资产｜道具名`
- `资产缺口｜本集`

检查点：

- 人物只来自人物目录、角色卡、对白说话人或剧本明确角色名。
- 不把动作、身份词、状态词和半截句子当人物。
- 资产字段要能支撑图片 Prompt：外观、服装、材质、状态、一致性锁定、用途。

## 阶段 3：图片 Prompt / LookDev

适用场景：

- 角色参考图、场景图、道具图、状态变体、LookDev 风格帧、局部编辑。

参考能力：

- `short-drama-image-prompts`：短剧项目资产图规格。
- `lira`：通用图像 Prompt 诊断、模型路由、编辑提示词。
- `shot-drama-scene-layout`：场景参考图、四视角、空间布局。

画布产出：

- `图片 Prompt｜角色名｜标准设定`
- `图片 Prompt｜场景名｜空间基准`
- `图片 Prompt｜道具名｜标准道具`
- `LookDev｜风格帧`
- `场景布局｜地点名｜四视角`

检查点：

- 角色图锁定身份、外观、服装、关键道具和一致性。
- 场景图锁定空间 DNA、入口、家具、光源、材质和隐藏区域补全规则。
- 道具图避免文字伪影；需要文字时用空白承载物和后期文字层。
- 现有图片编辑优先写“修改内容”和“严格保持不变”。

## 阶段 4：分镜 / 关键帧

适用场景：

- 已有剧本和资产，需要镜头表、场次视觉计划、关键帧提示词、连续性边界。

参考能力：

- `short-drama-storyboard`：镜头、关键帧、覆盖设计、连续性边界。

画布产出：

- `分镜表｜第 N 集`
- `场次视觉计划｜场次名`
- `关键帧 Prompt｜镜头 ID`
- `连续性检查｜第 N 集`

检查点：

- 每个镜头写清戏剧目的、可见行动、空间关系、起止状态和连续性约束。
- 关键帧冻结的是“状态点”，不是把整段视频动作写成一张图。
- 分镜要能进入视频 Prompt，不只是文学摘要。

## 阶段 5：视频 Prompt / 表演层

适用场景：

- 逐镜视频 Prompt、图生视频、文生视频、即梦任务单、Seedance/Higgsfield 等平台 Prompt。

参考能力：

- `short-drama-video-prompts`：项目内逐镜视频规格。
- `video-prompt-director`：非项目化视频 Prompt 快速输出。
- `acting`：目标、障碍、策略、节拍、潜台词、身体状态。

画布产出：

- `视频 Prompt｜镜头 ID`
- `表演层｜镜头 ID`
- `外部任务单｜平台｜镜头 ID`
- `验收标准｜镜头 ID`

检查点：

- 角色表演写目标和策略，不直接写“很生气”“很悲伤”。
- 写清参考图上传顺序、`@` 引用、时长、比例、模型、禁改项和验收标准。
- 一个视频 Prompt 只覆盖一个清晰镜头或一个明确合并段落。

## 阶段 6：外部生产 / 验收

适用场景：

- 用户要把图片、视频、TTS、音乐或候选视频导入生产包。

画布产出：

- `外部任务单｜平台｜镜头 ID`
- `候选验收｜镜头 ID`
- `剪辑备注｜第 N 集`
- `问题清单｜生产包`

检查点：

- 生产动作需要用户明确确认。
- 候选视频必须记录通过、失败、重试原因和采用版本。
- 不生成剪映私有草稿，不冒充已经调用外部平台。
