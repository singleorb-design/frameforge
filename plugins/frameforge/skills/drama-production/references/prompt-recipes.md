# FrameForge 短剧生产 Prompt Recipes

本文件提供可落到画布节点的结构化 Prompt 模板。使用时按任务类型选一节，不要一次加载所有方法。

## 通用输出原则

- Prompt 正文默认中文。
- 避免空泛词，例如“电影感”“高级感”“震撼”，除非后面有具体镜头、光线、构图和动作支撑。
- 每条 Prompt 都要包含用途、输入来源、比例、正向 Prompt、负向 Prompt 或禁改项。
- 需要给外部工具复制时，用清晰分段，少解释，多给可执行文本。

## 角色标准参考图

用于人物资产节点或角色图片 Prompt 节点。

```markdown
用途：角色标准参考图
比例：3:2 或用户指定
输入来源：剧本/人物卡/选中节点

正向 Prompt：
高质量动画 3D 短剧角色设定图，角色为【角色名】，【身份与戏剧功能】。
外观：【年龄感、脸型、五官、发型、体态】。
服装：【服装款式、颜色、材质、磨损或整洁程度】。
关键道具：【道具与佩戴/持有方式】。
一致性锁定：【必须在后续镜头保持不变的脸、发型、服装、道具、色彩】。
构图：全身或三分之二身，轻微侧前方，主体完整，姿态自然，背景简洁不抢主体。
画质：超清细节，主体锐利，眼睛高光清晰，材质纹理清楚，4K，sharp focus，high detail，crisp edges。

负向 Prompt：
不要多人，不要文字水印，不要多余肢体，不要脸部变形，不要过度磨皮，不要低清晰度，不要强景深虚化，不要改变关键服装和道具。
```

## 场景空间基准图

用于场景资产、四视角、空间布局。

```markdown
用途：场景空间基准图
比例：16:9 或用户指定
输入来源：剧本场景/参考图/选中节点

正向 Prompt：
高质量动画 3D 短剧场景设计板，地点为【场景名】。
空间功能：【这里发生什么戏，人物如何进入、停留、对峙或离开】。
空间 DNA：【墙面、地面、天花、门窗、主要家具、动线、层高、材质】。
光线：【主光源位置、色温、阴影、时间段】。
镜头基准：建立清晰轴线，展示入口、主要表演区、关键道具位置和可反打方向。
连续性锁定：【门窗位置、家具位置、道具位置、光源方向、颜色和材质】。
画质：超清细节，空间边缘清晰，材质纹理明确，高清写实动画，4K，sharp focus。

负向 Prompt：
不要随机新增门窗，不要改变主要家具位置，不要生成文字招牌，不要过度装饰，不要四个视角变成四个不同房间。
```

## 道具标准图

```markdown
用途：道具标准参考图
比例：1:1 或用户指定
输入来源：剧本/道具卡/选中节点

正向 Prompt：
高质量动画 3D 道具设定图，道具为【道具名】。
外形：【轮廓、大小、结构、材质、颜色】。
状态：【新旧、破损、污渍、发光、使用痕迹】。
戏剧用途：【它在剧情里证明、触发或改变什么】。
构图：单个道具居中，完整可见，中性背景，光线均匀，细节清晰。
一致性锁定：【后续镜头必须保持的形状、材质、颜色、标记】。

负向 Prompt：
不要文字乱码，不要水印，不要多件不同道具，不要改变核心形状，不要把道具变成角色。
```

## LookDev 风格帧

```markdown
用途：LookDev 风格帧
比例：9:16 或 16:9
输入来源：项目视觉方向/参考图/场景

正向 Prompt：
高质量动画 3D 短剧 LookDev 风格帧。
题材与情绪：【题材、观众情绪回报】。
视觉风格：【材质、镜头、色彩、光线、角色渲染、背景复杂度】。
场景样例：【一个能代表本剧的场面】。
制作边界：【低成本可复用资产、角色数量、场景规模、避免难生成内容】。
画质：主体锐利，细节丰富，4K，high detail，crisp edges。

禁改项：
不改变已接受角色身份，不改变题材承诺，不引入无法持续复用的复杂设定。
```

## 分镜节点

每个镜头节点建议包含：

```markdown
镜头 ID：【S01-001】
场次：【场次名】
时长：【秒数】
景别：【远景/中景/近景/特写】
戏剧目的：【这一镜让观众获得什么信息、权力变化或情绪回报】
开始状态：【人物、场景、道具在镜头开始时的可见状态】
动作过程：【可被看见的行动，不写抽象心理】
结束状态：【镜头结束时发生了什么变化】
镜头语言：【机位、运动、焦点、构图】
声音/台词：【对白、环境声、音乐 Cue】
连续性锁定：【人物位置、道具位置、光线方向、屏幕方向、服装状态】
```

## 关键帧 Prompt

```markdown
用途：关键帧 / 首帧 / 尾帧
镜头 ID：【S01-001】
比例：【9:16 / 16:9】
来源：【分镜节点、资产节点、参考图】

Prompt：
冻结镜头【S01-001】的【开始/高潮/结束】状态。
画面中：【人物和道具的明确位置】。
人物行为：【此刻正在做的一个可见动作】。
表情与身体：【由目标和压力产生的身体状态，不直接堆情绪词】。
场景与光线：【地点、光源、时间、材质】。
镜头：【景别、机位、焦点、构图】。
连续性：【必须保持的角色外观、场景布局、道具状态】。

负向 Prompt：
不要多余人物，不要文字水印，不要改变服装道具，不要运动模糊，不要错误手指，不要脸部漂移。
```

## 视频 Prompt

```markdown
镜头 ID：【S01-001】
模式：【文生视频 / 图生视频 / 首尾帧 / 多参考 / 全能参考】
比例：【9:16 / 16:9】
时长：【4-8 秒】
参考上传顺序：
1. 【角色/场景/首帧引用】
2. 【可选道具/尾帧引用】

生成视频：【X 秒】，【角色名】在【场景名】中为了【目标】采取【策略】，但受到【障碍】阻挡。
开始：【开始状态】。
过程：【动作过程，包含节拍变化、距离变化、视线和手部动作】。
结束：【结束状态，说明信息/权力/关系/物理状态怎样变化】。
镜头：【景别、机位、运动、焦点变化】。
表演：【身体重心、呼吸、停顿、倾听反应、潜台词泄漏】。
声音：【对白、环境声、音乐 Cue，如平台不支持音频则作为后期建议】。
连续性禁改：【角色外观、服装、道具、场景布局、光线方向、屏幕方向】。

负向约束：
不要换脸，不要换衣服，不要新增人物，不要改变空间布局，不要文字乱码，不要大幅镜头跳切，不要肢体畸形，不要主体失焦。

验收标准：
1. 【角色身份和外观是否稳定】
2. 【动作是否完成】
3. 【节拍变化是否可见】
4. 【结尾状态是否满足下一镜】
```

## 表演层增强

当用户要求“更真实”“不要假”“表演更有戏”时，把镜头里的情绪词改成行动逻辑。

```markdown
角色：【角色名】
场景目标：他/她此刻要从【对象】那里得到【具体结果】。
障碍：阻止目标达成的是【外部障碍】和/或【内部障碍】。
失败代价：如果失败，会失去【关系/地位/信息/生命/机会】。
策略变化：
1. 【第一策略：施压/讨好/试探/威胁/拖延】
2. 【策略失败后的变化】
3. 【最后一刻的选择】
身体状态：【重心、呼吸、速度、开放程度、手头事务】
潜台词：【说出口的话】背后真正想表达的是【真实意图】。
倾听反应：对手说到【关键词】时，角色先【微动作/停顿/视线变化】，再开口。
```
