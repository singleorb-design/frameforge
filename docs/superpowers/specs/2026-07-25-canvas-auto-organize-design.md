# 画布一键整理设计

## 背景

画布已经包含普通节点、自由分组、图片批次、人物卡组、角色资产包以及大量自动生成的连线。随着 AI 漫剧生产链增长，节点会逐渐散乱，用户需要一个能理解画布关系的一键整理能力，而不是简单的网格排列。

## 已确认决策

- 有选中节点时：只整理选中节点形成的范围。
- 没有选中节点时：整理整个画布。
- 固定从左到右布局。
- 整理完成后自动缩放并居中显示整理结果。
- 使用成熟的 `@dagrejs/dagre` 作为有向图布局引擎。

## 目标

- 按连线方向将源节点放在左侧，下游节点逐层向右。
- 同一层节点纵向排列，并尽量减少连线交叉。
- 图片批次、人物卡组、角色资产包作为一个布局单元处理，不拆散主子关系。
- 普通 Group 作为一个布局单元移动，内部节点保持相对位置。
- 整理动作进入现有撤销历史。
- 整理后自动适配视口。

## 非目标

- 不重新计算连线控制点，继续使用现有连接渲染。
- 不自动改变节点尺寸。
- 不改变批次/人物卡组/角色资产包的展开状态。
- 不重排普通 Group 内部节点。
- 不处理跨 Group 的自动归属变更。
- 不提供上下方向或右到左方向选项。

## 工具栏入口

在画布底部工具栏增加“一键整理”图标按钮。

行为：

```text
有选中节点 -> 整理选中范围
无选中节点 -> 整理全画布
```

整理完成后显示提示：

```text
已整理 18 个节点
```

如果当前没有节点，不执行布局并提示“画布暂无节点”。

## 布局单元

### 普通节点

普通节点独立参与 Dagre 布局。

### 图片批次

- 图片批次主节点作为布局单元。
- 图片子节点不直接传给 Dagre。
- 主节点移动后，子节点保持相对主节点的现有偏移。
- 折叠和展开状态保持不变。

### 人物卡组

- 人物卡组主节点作为布局单元。
- 人物卡子节点不直接传给 Dagre。
- 主节点移动后，人物卡子节点保持现有相对偏移。

### 角色资产包

- 角色资产包主节点作为布局单元。
- 三视图、表情九宫格、景别参考图片不直接传给 Dagre。
- 主节点移动后，子图片保持现有相对偏移。

### 普通 Group

- Group 节点作为布局单元。
- Group 内部节点不直接参与 Dagre。
- Group 移动后，内部节点整体平移相同距离。

## 选中范围

当存在选中节点时：

- 以选中节点为初始集合。
- 如果选中了批次/人物卡组/资产包主节点，自动包含其所有子节点作为移动成员。
- 如果选中了子节点，不自动移动未选中的主节点。
- 如果选中了普通 Group，自动包含组内所有节点。
- 只使用整理范围内部的连线进行 Dagre 布局。
- 范围之外的节点不移动。

## Dagre 配置

```ts
{
  rankdir: "LR",
  ranksep: 120,
  nodesep: 56,
  edgesep: 20,
  marginx: 0,
  marginy: 0,
  ranker: "network-simplex"
}
```

每个布局单元使用实际 `width` / `height`。

Dagre 返回中心坐标，转换为画布左上角坐标：

```ts
position.x = result.x - node.width / 2
position.y = result.y - node.height / 2
```

## 无连线节点

没有连线的节点仍参与布局。

建议策略：

- Dagre 负责所有布局单元。
- 孤立节点作为独立图分量。
- 布局后按整体边界保持统一间距。

## 位置归一化

整理后将布局结果平移到接近当前整理范围左上角的位置，避免节点突然跳到世界坐标原点。

```text
新布局最小 x/y
→ 对齐整理前范围的最小 x/y
```

这样既完成整理，也尽量保留用户对画布区域的空间记忆。

## 自动适配视口

整理完成后计算被整理节点的边界：

```ts
left / top / right / bottom
```

加入约 `96px` 屏幕边距，计算缩放：

```ts
scale = min(
  viewportWidth / layoutWidth,
  viewportHeight / layoutHeight,
  1
)
```

缩放限制在现有画布允许范围 `0.05 - 5`，并居中边界中心。

## 撤销

整理通过一次 `setNodes` 更新完成，沿用现有历史监听。

用户点击一次撤销，应恢复整理前的全部节点位置和视口。

## 文件落点

- `web/package.json`
  - 新增 `@dagrejs/dagre`
  - 新增 `@types/dagre` 或使用包内类型
- `web/src/lib/canvas/canvas-auto-layout.ts`
  - 构建布局单元
  - 提取范围内连线
  - 调用 Dagre
  - 计算主节点和成员节点新位置
  - 计算适配视口
- `web/src/components/canvas/canvas-toolbar.tsx`
  - 新增“一键整理”按钮
- `web/src/pages/canvas/project.tsx`
  - 组织选中范围
  - 调用布局工具
  - 更新节点与视口
  - 提示整理结果

## 人工验证

- 无选中节点时整理整个画布。
- 有选中节点时只移动选中范围。
- 连线方向保持从左到右。
- 图片批次、人物卡组、角色资产包的主子结构不被拆散。
- 普通 Group 内部相对位置不变。
- 折叠状态不改变。
- 整理后所有目标节点自动适配到视口。
- 撤销可恢复整理前的位置。
- 无节点时显示提示且不报错。
