# AI 漫剧生产流程验收清单

本文档用于验收本次新增的 AI 漫剧生产流程。建议严格按顺序执行：先完成 P0 必测项，再决定是否执行 P1 回归项。

## AI 镜头预整理与异常审核

### 自动整理

- [ ] 用剧本、角色设定、场景卡组和道具卡组连接结构化分镜配置并生成；分镜节点出现后配置节点应继续保持运行，直到整集 AI 整理结束。
- [ ] 生成完成提示应包含镜头总数、自动确认数、需处理数和整理失败数。
- [ ] 对白说话人与现有角色设定名称一致时，应自动绑定对应角色；默认界面不得显示内部版本号。
- [ ] 镜头文本为“沈夜手持玉佩”时，应将沈夜识别为人物、将玉佩识别为道具；不得出现“缺少人物：手持玉佩”。目录已有“旧玉佩”时应自动绑定，历史同类错误异常刷新后应清除。
- [ ] “身份”“角色设定”“人物设定”“镜头”“动作”“场景”等语义词不得被识别为人物或显示为“缺少人物”；刷新旧画布后同类异常应自动清除。
- [ ] “都废了”“配不上”“认命”“笑话”等状态、评价或口语短句不得被识别为人物或显示为“缺少人物”；刷新旧画布后同类异常应自动清除。
- [ ] 人物识别只能来自人物目录、角色卡或对白说话人；不得从普通剧情句子中用“少主/小姐/师兄”等称谓规则猜测新人物名。
- [ ] AI 返回的“缺少人物”若不在人物目录、角色卡、对白说话人或候选资产中，应在解析阶段丢弃；“退婚也正”“独自”等半截句子不得显示为缺少人物。
- [ ] 已存在“苏婉儿”角色设定但旧镜头仍显示“缺少人物：苏婉儿”时，刷新画布或上传苏婉儿参考图后必须自动绑定角色并关闭该异常；此前中断的 AI 补齐失败不可继续显示，已有参考图应自动接入已确认镜头。
- [ ] 项目中存在多个同名“苏婉儿”记录时，应优先绑定已上传视觉参考的角色；打开受影响镜头后必须立即清除旧“缺少人物”异常，不要求再次刷新页面。
- [ ] 多个同名角色仍无法自动判断时，异常卡必须展示候选角色按钮；点击候选后应绑定该角色、关闭“匹配到多个资产”异常并继续自动推进。
- [ ] 镜头没有必须处理的问题时，应自动采用 AI 推荐生成方式并进入“准备画面”；不得再要求确认镜头或确认生成方案。
- [ ] 已上传的角色、场景和道具参考图必须自动带入对应镜头；首帧、尾帧或关键帧上传后应直接标记为可用，不要求再点“通过”。
- [ ] 准备画面页的当前首帧、尾帧、关键帧或参考图必须显示图片缩略图预览，不得只显示文件名。
- [ ] 普通警告不得阻塞自动推进；只有缺少必填镜头内容、缺少场景或阻塞级素材异常才暂停流程，并在“必须处理”中明确展示。
- [ ] 场次已经绑定正式场景 ID 时，应直接沿用；没有 ID 时按场次名称匹配。
- [ ] 生成配置直接连接的资产和画布资产同名时，应优先选择连线资产。
- [ ] AI 不得新增镜头、修改镜头 ID、镜号、顺序、台词、剧情节拍或资产 ID。
- [ ] 高置信度且无阻塞、复核、连续性错误的镜头应自动进入“已确认”。
- [ ] 让一个 AI 批次返回非法结果，其他批次仍应保留成功结果；分镜表不得回滚。
- [ ] 打开旧分镜后点击“重新检查整集”，来源剧本的“主要人物”章节应补充到结构化角色词典；镜头文本明确出现该角色名但没有人物卡时应显示“缺少人物”阻塞异常，而不是“空镜可忽略”。

### 异常审核

- [ ] 双击分镜表进入生产看板，顶部应显示“已自动确认 / 需处理 / 整理失败”数量。
- [ ] 默认筛选“需处理”，正常镜头不应占据异常列表。
- [ ] 点击“重新整理异常”只重跑异常、失败和待整理镜头。
- [ ] 点击“重新检查整集”重跑全部镜头，但不覆盖人工锁定字段。
- [ ] 点击“AI 检查整集”后，生产看板应说明其只重新匹配资产、补镜头摘要/状态、归集异常，不会改写台词、镜头顺序或人工锁定字段。
- [ ] 检查期间按钮应显示“AI 正在检查镜头”并禁用重复点击，面板应显示逐场检查提示。
- [ ] 检查结束后统计应更新，并提示自动确认、需处理和失败数量。
- [ ] 点击异常镜头“查看并处理”应直接进入该镜头工作台。

### 镜头工作台

- [ ] 默认页应显示可读镜头摘要、开始/动作/结束流程和资产匹配依据。
- [ ] 默认页不应直接暴露 `informationGain`、`screenDirection`、`editRelation` 等内部字段名。
- [ ] 专业字段应收在“高级编辑”中，功能仍可编辑和保存。
- [ ] 修改专业字段并保存后，该字段应显示“人工修改优先”。
- [ ] 再次运行 AI 整理，人工锁定字段不得变化。
- [ ] 点击某字段“允许 AI 重写”后重新整理，该字段才允许更新。
- [ ] 点击“允许 AI 重写全部”后应解除整镜人工锁定。
- [ ] 无未保存修改、无阻塞异常的草稿镜头，应自动采用推荐生成方式并进入 `plan-approved`，默认界面不显示确认按钮。
- [ ] 默认工作台应仅显示“检查分镜 / 准备画面 / 外部生成 / 回传结果”四步，不显示 `v1/v2`、版本化资产、历史版本、能力档案或手动版本选择器。
- [ ] 自动准备后默认进入“准备画面”；必需画面上传后直接采用并出现“下一步：生成外部任务”；任务准备好后出现“下一步：上传外部生成结果”。手动换素材和恢复此前保存内容必须收进“更多调整”。

### 缺失资产

- [ ] 缺少关键资产时，相关镜头应出现聚合的缺失人物、场景或道具异常。
- [ ] 异常卡应展示正向 Prompt、负向 Prompt、影响镜头和建议资产名。
- [ ] 点击“复制 Prompt”应复制完整正负 Prompt。
- [ ] 点击“AI 生成资产卡”只产生草案，不应立刻写入正式资产目录或画布。
- [ ] 点击“AI 生成资产卡”后，异常卡应立即显示“AI 正在生成资产卡”并禁用重复操作；成功后展示草案，失败后在卡内展示错误原因和“重新生成资产卡”。
- [ ] 模型将唯一草案包装成单元素数组，或数组中只有一个名称与建议资产名一致的对象时，应正常展示草案；无法唯一确定对象时必须提示“资产卡草案返回了多个对象，无法确定应采用哪一项”，不得随机采用。
- [ ] 模型把资产字段平铺在草案根对象、放入 `asset` / `assetCard` / `payload`，或遗漏 `recommendedRatio` 时，应按当前资产类型归一化并校验；比例可推导为人物 `3:2`、场景 `16:9`、道具 `1:1`，但创作核心字段缺失仍必须显示具体字段错误。
- [ ] 草案前点击“复制 Prompt”，复制内容应包含相关镜头/对白上下文、高质量动画 3D 国风玄幻漫剧、PBR 材质、完整主体构图、负向 Prompt 和推荐比例。
- [ ] 草案生成后点击“复制 Prompt”，人物 Prompt 应包含身份、外貌、服装、关键道具、一致性锁定、全身三分之二侧前方构图，以及正负 Prompt、推荐比例和外部制作流程。
- [ ] 点击“采用并生成参考图”后，图片节点记录的 Prompt 必须是生产级 3D 编译 Prompt，不能是仅包含资产名的通用 Prompt。
- [ ] 角色设定、场景和道具卡均应显示“上传外部生成图”入口；上传后生成连接的标准参考图图片节点与持久化快照记录。
- [ ] 对同一资产再次上传，不得替换或删除此前参考图；默认画面只展示普通参考图名称，不展示内部版本号。
- [ ] 角色设定回填标准参考图后，触发“视觉参考”生成，三视图应以该图作为图生图母版。
- [ ] 上传角色、场景或道具外部参考图后，所有绑定该素材且没有真实阻塞的镜头应自动接入此图；镜头工作台显示“已接入 N 张视觉参考”，整集看板和镜头节点显示参考数量，无需再次上传或人工确认。
- [ ] 打开绑定该资产的镜头准备画面页时，回填图应已经自动作为对应人物、场景或道具参考接入。
- [ ] 资产卡生成中应显示已等待秒数和“停止生成”；停止后卡片恢复可重新生成状态。
- [ ] 资产卡生成超过 90 秒后，应显示超时错误和外部 Prompt，不应永久停在生成中。
- [ ] 刷新页面后，已中断的资产卡生成必须显示“页面刷新导致资产卡生成中断”，可立即重试。
- [ ] 同一缺失资产被多个镜头使用时，只生成一份草案。
- [ ] 点击“采用资产卡”后，应创建正式版本化资产并加入对应人物/场景/道具卡组。
- [ ] 采用后所有相关镜头应自动绑定该资产，同名缺失异常应变为已解决。
- [ ] 满足条件的相关镜头应在重新校验后自动确认。
- [ ] 点击“采用并生成参考图”应在资产卡后创建真实图片节点并建立连线。
- [ ] 生图失败时资产卡、卡组连线和镜头绑定必须保留。

### 持久化

- [ ] 刷新页面后应保留 preflight 状态、摘要、字段来源、人工锁定、异常、整理批次和资产草案。
- [ ] 撤销/重做应恢复镜头内容与人工锁定状态。
- [ ] 导出画布并重新导入后，上述数据应完整恢复。

# P0 必测

## 1. 本地画布恢复

### [ ] P0-01 旧画布正常显示

操作：

1. 打开 [http://localhost:3000/canvas](http://localhost:3000/canvas)。
2. 等待画布列表完成加载。
3. 找到本次开发前已经创建的旧画布。
4. 打开旧画布。

预期：

- 旧画布仍存在。
- 原节点、图片、人物卡、角色资产包和连线仍能显示。
- 页面不会进入 React 错误边界。
- 控制台不再出现 `productionRef.current` 相关错误。

### [ ] P0-02 127.0.0.1 自动切换到 localhost

操作：

1. 打开 `http://127.0.0.1:3000/canvas?test=origin#verify`。

预期：

- 自动跳转到 `http://localhost:3000/canvas?test=origin#verify`。
- 路径、查询参数和 hash 保持不变。
- 页面显示与 localhost 相同的画布列表。
- 不会创建或展示另一套空画布库。

### [ ] P0-03 刷新后旧画布仍存在

操作：

1. 在旧画布页面刷新两次。
2. 返回画布库。

预期：

- 画布、节点和连线不消失。
- 刷新不会把旧项目覆盖为空项目。

## 2. 结构化分镜生成

### [ ] P0-04 准备生成链路

操作：

1. 创建或复制一个测试画布。
2. 添加剧本节点并粘贴完整 Markdown 剧本。
3. 添加文本节点，输入：

```text
生成约90秒竖屏 AI 漫剧分镜，强调情绪特写、小动作、连续性和结尾悬念。
```

4. 准备人物卡组。
5. 添加生成配置节点。
6. 将剧本、导演要求、人物卡组直接连接到配置节点。
7. 配置节点选择：
   - 模式：`文本`。
   - 输出：`结构化分镜`。

预期：

- 配置节点输入统计能识别剧本、导演要求和人物卡组。
- 选择“结构化分镜”后，底部“开始生成”按钮仍完整可见。
- “开始生成”按钮可用。
- 人物卡组可通过 `@` 引用进入组装提示词。

### [ ] P0-05 成功生成结构化分镜

操作：

1. 点击“开始生成”。
2. 等待模型返回并完成校验。

预期：

- 生成 1 个场景卡组及若干场景卡。
- 生成 1 个道具卡组及关键道具卡；没有关键道具时允许不生成道具卡组。
- 生成 1 个分镜表主节点。
- 生成多个镜头子节点。
- 形成 `配置 -> 主节点 -> 子节点` 连线。
- 镜头按场次和镜号排序。
- 不出现模型 `<think>` 内容。
- 不创建半成品文本节点或 JSON 文档节点。

### [ ] P0-06 分镜主子节点交互

操作：

1. 双击场景卡组。
2. 双击道具卡组。
3. 点击分镜表上的展开/收起按钮。
4. 反复展开和收起两次。

预期：

- 子节点有飞出/飞回动画。
- 折叠后子节点和内部连线隐藏。
- 展开后子节点和连线恢复。
- 不出现主节点存在但子节点为空的情况。

### [ ] P0-07 一键整理结构化分镜

操作：

1. 展开场景卡组、道具卡组和分镜表。
2. 点击“一键整理”。
3. 再执行一次撤销。

预期：

- 主子结构不被拆散。
- 展开的子节点按两列网格排列，不重叠。
- 整理后视口自动适配。
- 撤销恢复整理前位置。

### [ ] P0-08 结构化模型错误不产生脏数据

操作：

1. 使用一个会返回非 JSON 的模型配置，或故意在导演要求中要求输出非法格式。
2. 点击生成。

预期：

- 配置节点显示明确错误。
- 错误包含 JSON 或字段路径信息。
- 原始模型输出保留在配置节点数据中。
- 不创建场景、道具、分镜或镜头半成品节点。

## 3. 镜头工作台

### [ ] P0-09 打开和退出工作台

操作：

1. 双击任意镜头节点。
2. 按 `Esc`。
3. 再次双击镜头。

预期：

- 进入全屏镜头工作台。
- 左侧按场次显示镜头列表。
- 中间显示镜头定义。
- 右侧显示资产绑定、阻塞项和模式推荐。
- `Esc` 可退出。

### [ ] P0-10 未保存修改保护

操作：

1. 修改开始状态或动作过程。
2. 不保存，直接切换到其他镜头。
3. 选择继续编辑。
4. 再次切换，选择放弃。
5. 修改后直接关闭工作台。

预期：

- 切换镜头前提示是否放弃修改。
- 选择继续编辑后停留当前镜头。
- 选择放弃后切换镜头。
- 关闭工作台时同样提示。

### [ ] P0-11 镜头保存和 revision

操作：

1. 修改剧情目的、开始状态、动作、结束状态、时长和音效 Cue。
2. 点击“保存镜头”。
3. 在没有继续修改时再次观察保存按钮。

预期：

- revision 只增加 1 次。
- 没有修改时保存按钮不可用。
- 镜头节点标题和工作台内容同步更新。
- 刷新后修改仍存在。

### [ ] P0-12 镜头素材绑定

操作：

1. 为镜头选择人物、场景、道具。
2. 分别选择角色、场景和道具。
3. 仅在必要时填写镜头内状态。
4. 保存镜头。

预期：

- 人物、场景、道具绑定写入镜头。
- 默认界面仅显示角色、场景和道具名称，不展示版本选择。
- 切换镜头再返回，绑定和状态仍存在。

### [ ] P0-13 阻塞项阻止确认

操作：

1. 清空结束状态。
2. 清除场景绑定。
3. 保存。
4. 点击“确认镜头”。

预期：

- 工作台显示 error 级阻塞项。
- 无法确认镜头。
- 补全结束状态和场景后可成功确认。

### [ ] P0-14 镜头历史恢复

操作：

1. 连续保存两个不同版本。
2. 在历史版本中恢复较早版本。

预期：

- 恢复操作不会删除新历史。
- 恢复内容作为一个新的 revision 保存。
- 画布撤销/重做可同步恢复 Production 和镜头节点。

## 4. 四种生成模式

### [ ] P0-15 系统推荐与自动采用

操作：

1. 打开一个没有真实阻塞的镜头。
2. 查看系统自动选择的生成方式。
3. 进入准备画面。

预期：

- 系统推荐首帧、首尾帧、智能多帧或全能参考之一。
- 无真实阻塞时自动采用推荐方式，不显示确认镜头或确认方案按钮。
- 有阻塞时保持“需要处理”，解决后自动继续。
- 自动采用后镜头状态显示为“准备画面”。

### [ ] P0-16 编辑后方案自动失效

操作：

1. 对已经确认方案的镜头修改动作并保存。

预期：

- 镜头状态回到草稿。
- 当前方案从 approved 变为 recommended。
- 旧 approved 方案进入方案历史。
- 后续需要重新确认镜头和方案。

## 5. 控制资产

### [ ] P0-17 首帧模式

操作：

1. 确认首帧模式。
2. 进入“控制资产”。
3. 复制首帧 Prompt。
4. 上传一张图片。
5. 点击“通过”。

预期：

- 首帧显示为必需项。
- 上传后状态为待审核。
- 审核通过后进入“控制资产就绪”。

### [ ] P0-18 首尾帧模式

操作：

1. 确认首尾帧模式。
2. 上传首帧和尾帧。
3. 只审核通过首帧。
4. 再审核通过尾帧。

预期：

- 只通过首帧时不能进入就绪。
- 首帧和尾帧都通过后进入就绪。
- 每项可上传新版本和切换版本。

### [ ] P0-19 智能多帧模式

操作：

1. 确认智能多帧模式。
2. 上传第一张关键帧。
3. 点击“添加下一关键帧”，上传第二张。
4. 分别审核。

预期：

- 两张关键帧是两个有顺序的记录，不是同一图片的历史版本。
- 少于两张通过时不能就绪。
- 两张或以上通过后进入就绪。
- 上传顺序在任务单中保持一致。

### [ ] P0-20 全能参考模式

操作：

1. 确认全能参考模式。
2. 上传人物、场景或道具图片参考至少一项。
3. 审核通过。

预期：

- 人物、场景、道具、动作、运镜、音频参考项可见。
- 图片参考可以上传。
- 动作、运镜和音频参考明确提示从已有画布资产关联。
- 至少一项参考审核通过后可进入就绪。
- 页面不存在“生成视频”按钮。

### [ ] P0-21 控制资产固定到画布

操作：

1. 将审核通过的控制图固定到画布。
2. 再次点击固定。
3. 删除固定出来的图片节点。

预期：

- 第一次创建普通图片节点并连接镜头。
- 第二次不重复创建，而是聚焦已有节点。
- 删除图片投影不会删除工作台中的控制资产记录。

## 6. 即梦任务单

### [ ] P0-22 编译即梦任务单

操作：

1. 进入“即梦任务单”。
2. 选择能力档案、模型、比例、时长和分辨率。
3. 根据镜头声音需求选择是否启用原生音频。
4. 点击“编译任务单”。

预期：

- 不支持的模式、比例、时长、分辨率或参考数量会阻止编译。
- 任务单包含：
  - 模型和模式。
  - 上传顺序。
  - 参考职责。
  - `@角色`、`@场景`、`@道具` 等引用。
  - 最终 Prompt。
  - 禁止项。
  - 即梦操作步骤。
  - 验收标准。
  - 失败重试方法。

### [ ] P0-23 发布、复制和固定任务单

操作：

1. 发布任务单。
2. 复制 Prompt。
3. 复制完整任务单。
4. 固定到画布。

预期：

- 任务单状态为 published。
- 复制内容完整。
- 固定后生成 Markdown 文档节点并连接镜头。
- 重复固定不创建重复节点。

### [ ] P0-24 任务单 stale

操作：

1. 发布任务单。
2. 替换一个控制资产版本，或修改镜头后重新保存。

预期：

- 旧任务变为 stale。
- 旧任务仍可查看和审计。
- 必须重新确认并编译新任务。

### [ ] P0-25 能力档案版本

操作：

1. 打开“更新能力档案”。
2. 修改一个模型时长或参考数量。
3. 创建新版本。

预期：

- 新版本追加保存。
- 旧版本仍存在。
- 已发布任务中的档案快照不变化。
- 只有用户选择新档案并重新编译，才使用新能力。

## 7. 即梦候选验收

### [ ] P0-26 上传多个候选

操作：

1. 进入“候选验收”。
2. 选择来源任务单。
3. 上传两个 MP4/MOV。
4. 切换候选。

预期：

- 两个候选独立保存。
- 视频可以播放。
- 每个候选记录来源任务 ID 和版本。
- 上传不等于采用。

### [ ] P0-27 验收与采用区间

操作：

1. 设置入点、出点、目标时长。
2. 填写变速、定格、裁切、补帧、转场、调色和剪辑备注。
3. 勾选全部验收项。
4. 保存验收。
5. 点击“采用候选”。

预期：

- 未保存修改时不能采用。
- 有未通过验收项时不能采用。
- 入点/出点非法时不能采用。
- 通过后镜头状态进入“剪辑就绪”。

### [ ] P0-28 采用候选失效

操作：

1. 修改已经采用候选的验收信息并保存。
2. 或修改镜头、控制资产、发布新任务。

预期：

- 原采用关系被清除。
- 旧候选变为 candidate 或 stale。
- 镜头退出“剪辑就绪”，需要重新验收采用。

### [ ] P0-29 候选固定到画布

操作：

1. 将已采用候选固定到画布。
2. 再次点击固定。

预期：

- 第一次创建普通视频节点并连接镜头。
- 第二次聚焦已有节点，不重复创建。
- 删除视频节点不删除候选记录。

- `control-frames/` 中是实际图片。
